火锅套餐毛利率计算器 · 多套餐

下拉切换套餐 → 点「编辑」填写 → 点「保存」同步到 Coze 数据库。默认只读防误改。

📋 已按你的 xlsx 格式导入 5 个套餐：菜品名字、分量、单位、零售价、团购价已铺好；能按分量反推出的「零售单价」已预填。
✍️ 毛利率只看「成本价」（红框=未填）；分量/单价/零售价只影响定价展示，改它们不会直接改毛利率。手动修改零售价的行会标黄锁定。
💾 编辑 / 保存：默认只读，点「编辑」解锁所有输入框，点「保存」把 5 个套餐 upsert 到 Coze 数据库（每套餐一行：meal_id / name / data）。Token 与 Database ID 在「Coze配置」里填，仅存本机。
🔄 从 Coze 加载：已存进库的数据，点此手动拉回（不会自动覆盖，内置默认值始终兜底，空/脏记录不会冲掉数据）。
⚠️ 首次部署：数据已内置在代码里，开箱即见；想多人填并集中留存，先在「Coze配置」填好凭证再「保存」。
Token 与 Database ID 仅存本机浏览器（localStorage），不会写进代码。Coze 数据库需含字段：meal_id(文本)、name(文本)、data(文本，存套餐JSON)。
